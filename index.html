    🚀 YouTube API 키 발급 상세 가이드

    본 서비스의 유튜브 분석 기능을 이용하시려면 아래 단계를 따라 API 키를 발급받아 등록해 주세요.

    왜 API 키가 무조건 있어야 하나요?
    🔑
    개인 신분증
    유튜브 도서관을 이용하기 위한 전용 출입증입니다.
    📊
    사용량 관리
    무분별한 데이터 요청을 막아 서버를 안전하게 보호합니다.
    ⚖️
    할당량 준수
    구글이 부여한 일일 무료 검색 점수를 개별적으로 사용합니다.
    Step 1 구글 클라우드 콘솔 접속

    1. 구글 검색창에 "YouTube Data API v3"를 검색합니다.
    2. 검색 결과 중 Google Cloud Console 사이트(console.cloud.google.com)로 표시된 항목을 클릭하여 접속합니다.
    3. 구글 계정으로 로그인합니다. (프로젝트가 없다면 안내에 따라 간단히 생성하세요.)

    Step 2 API 서비스 활성화

    1. 콘솔 화면 오른쪽 상단의 돋보기 모양(검색창)을 클릭합니다.
    2. 'YouTube Data API v3'를 입력하고 검색 결과에 나타나는 해당 API를 클릭합니다.
    3. 화면 중앙의 파란색 [사용] (Enable) 버튼을 클릭합니다.

    Step 3 API 키 생성 시작

    1. API가 활성화되면 왼쪽 메뉴 탭에서 [사용자 인증 정보] (Credentials) 메뉴를 클릭합니다.
    2. 화면 상단에 있는 [+ 사용자 인증 정보 만들기] 버튼을 누릅니다.
    3. 나타나는 옵션 중 [API 키]를 선택합니다.

    Step 4 API 키 상세 설정 (보안 및 제한)

    ※ 이 단계는 API 키의 안전한 사용을 위해 매우 중요합니다.

    1. API 키 이름: 본인이 알아보기 쉬운 이름(예: "My Youtube Analyzer")을 입력합니다.
    2. API 제한사항 설정: 화면 아래쪽의 [API 제한사항] 섹션에서 [키 제한] (Restrict key) 항목을 선택합니다.
    3. API 선택: Select APIs 드롭다운 메뉴를 누릅니다.
    4. 목록을 맨 아래로 내려 [YouTube Data API v3]를 찾아 체크한 후 [확인]을 누릅니다.
    5. 모든 설정을 확인했다면 하단의 [만들기] (또는 저장) 버튼을 클릭합니다.

    Step 5 키 복사 및 서비스 등록

    1. 화면에 표시된 생성된 API 키를 복사합니다.
    2. 만약을 위해 복사한 키를 메모장에 따로 저장해둡니다.
    3. 우리 앱의 [내 계정 관리] 또는 [프로필 페이지]로 이동하여 API 키 입력란에 붙여넣고 [저장] 버튼을 누르세요!
